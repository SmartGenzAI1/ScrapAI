# 🖥️ ScrapAI Frontend UI & Terminal

The **ScrapAI Frontend** is a modern, high-performance Single Page Application (SPA) built with **React 18** and **Vite**, styled with a futuristic Cyberpunk / Matrix HUD aesthetic.

---

## 🌟 Features

- **Live Telemetry Dashboard**: Real-time stats showing indexed pages, chunks, vectors, and active FlashRank neural re-ranking status.
- **Target Acquisition Module**: Enqueue single or multiple web targets with custom depth and priority.
- **Data Vault Explorer**: Search, inspect, and explore scraped documents and their sliced semantic chunks.
- **Cyber Master Terminal**: Interactive CLI terminal providing direct command-driven access to ScrapAI's backend.
- **⚡ FlashRank Relevance Badges**: Visual confidence and cross-encoder score badges on search results.

---

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
Build artifacts are placed in `dist/` and can be served directly by FastAPI or any static file server.
